# Клиент. Задача 6. Тайм-банк

Документ для разработчика Electron-клиента. Дополняет
[задачу 3](3_Hand.md) — таймер хода.

Правило общее для **всех форматов**: кэш, турнир, sit-n-go. Тайм-банк —
это про время, а не про деньги, поэтому ни одного «если кэш» в клиенте
быть не должно. Числа приходят с сервера.

---

## 1. Как это работает

На каждый ход у игрока два ресурса подряд:

1. **Обычное время** — `action_timeout_ms` из настроек комнаты. Личный
   запас при этом **не тратится**: за фолд мусора платить нечем.
2. **Тайм-банк** — личный запас. Включается сам, когда обычное время
   кончилось, а игрок ещё не сходил.
3. Кончился и банк — стол ходит за игрока: чек, если бесплатно, иначе фолд.

Банк списывается **по факту**: включился, игрок думал 4 секунды и сходил —
списались 4 секунды, а не весь запас.

За каждую сыгранную раздачу банк пополняется на `time_bank_refill`, но не
выше потолка `time_bank_ms`. Пополнение приходит вместе с концом раздачи —
отдельного события у него нет.

**Кнопки «использовать банк» нет и не будет.** Она требует решения ровно
в тот момент, когда игрок и так думает над рукой, а на лаге приходит уже
после автофолда. Клиент только показывает, что банк пошёл.

---

## 2. Что приходит с сервера

### `action_prompt` — как и раньше, плюс запас

```json
{
  "seat": 3,
  "action_seq": 42,
  "deadline_ms": 20000,
  "time_bank_ms": 30000,
  "legal_actions": { "fold": true, "check": false, "call": 40, "raise": {"min": 80, "max": 400} }
}
```

* `deadline_ms` — сколько осталось **обычного** времени.
* `time_bank_ms` — сколько всего в запасе у ходящего. Показывать его нужно
  **сразу**, а не в момент включения: игрок должен понимать, сколько у него
  есть сверху, пока принимает решение.

### `time_bank_started` — обычное время кончилось

```json
{ "seat": 3, "action_seq": 42, "time_bank_ms": 26500, "deadline_ms": 26500 }
```

Приходит **всем за столом**: соперники и так видят, что человек думает
дольше обычного, — прятать это незачем. С этого момента таймер идёт из
запаса, и его стоит показать иначе (другой цвет, отдельная полоса).

### В снапшоте

* `seats[].time_bank` — остаток запаса каждого игрока (мс). Публичен.
* `hand.time_bank_running` — идёт ли прямо сейчас отсчёт из запаса.
  Нужен подключившемуся в середине хода: он должен увидеть тот же таймер,
  что и остальные.
* `hand.deadline_ms` — сколько осталось у текущего таймера, какой бы из
  двух ни шёл.
* `you.time_bank` — свой остаток (то же число, что и в `seats`).

---

## 3. Что делает клиент

1. Рисует основной таймер по `deadline_ms` из `action_prompt`.
2. По `time_bank_started` переключает вид таймера и отсчитывает
   `deadline_ms` уже из этого события. Никакой арифметики над остатком
   запаса делать не надо — сервер прислал готовое число.
3. Остаток `time_bank` обновляет из снапшота и из `action_prompt`
   следующей руки. Локально уменьшать его по своему таймеру можно только
   для плавности анимации; источник истины — сервер.
4. При реконнекте берёт всё из снапшота: `deadline_ms` +
   `time_bank_running` дают то же состояние, что видят остальные.

Чего делать **нельзя**:

* считать, что банк тратится всегда — в обычное время он не трогается;
* показывать банк только тому, чей он: он публичен;
* отправлять что-либо для включения банка — сообщения на это нет;
* считать, что по истечении банка игрок всегда сбрасывает: если ход
  бесплатный, сервер сделает чек.

---

## 4. Настройки, от которых всё зависит

Оба числа приходят из шаблона комнаты и в разных форматах разные:

| Поле | Что это |
|---|---|
| `action_timeout_ms` | обычное время на ход |
| `time_bank_ms` | потолок личного запаса и его стартовое значение |
| `time_bank_refill` | сколько добавляется за сыгранную раздачу |

Ноль в `time_bank_ms` — законная конфигурация: банка нет, по истечении
обычного времени сразу ходит стол. Клиент обязан это пережить, не рисуя
пустую полосу и не деля на ноль.

---

## 5. Чек-лист приёмки

* [ ] Запас показан до того, как обычное время кончилось.
* [ ] По `time_bank_started` таймер визуально меняется, а не начинается
      заново без объяснений.
* [ ] Запас виден по каждому игроку, а не только по себе.
* [ ] После раздачи остаток вырос на `time_bank_refill`, но не выше
      `time_bank_ms`.
* [ ] Реконнект посреди чужого хода показывает тот же таймер, что и у всех.
* [ ] Комната с `time_bank_ms: 0` выглядит как обычный таймер без запаса.
* [ ] Клиент не шлёт на сервер ничего, связанного с банком.
