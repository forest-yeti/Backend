# Клиент. Задача 3. Раздача

Продолжает [задачу 2](2_CashGame.md): места и посадка уже есть, теперь стол
играет — блайнды, карты, улицы, торговля, вскрытие.

---

## 1. Когда раздача начинается

Как только за столом два игрока в игре, разыгрывается кнопка (§5 задачи 2),
а по окончании анимации **сразу стартует первая раздача**. Дальше раздачи
идут одна за другой с паузой 2 секунды — её хватает, чтобы увидеть итог.

`phase` в снапшоте: `idle` → `button_draw` → `hand` → `idle` → …

Игрок, севший с `waiting_for_bb`, вступает ровно тогда, когда большой блайнд
доходит до его места. До этого он получает снапшоты, но не карты, и в его
`you` держится `waiting_for_bb: true` — так и надо показывать: «ожидание
большого блайнда».

---

## 2. Раздача в снапшоте

К снапшоту стола добавилось поле `hand` (или `null`, если раздачи нет):

```json
"hand": {
  "street": "flop",
  "board": [{ "rank": 14, "suit": "S" }, { "rank": 7, "suit": "H" }, { "rank": 2, "suit": "C" }],
  "pot": 120,
  "bet": 40,
  "to_act": 3,
  "action_seq": 12,
  "deadline_ms": 14320,
  "seats": {
    "1": { "committed": 40, "total": 60, "status": "active", "cards": null },
    "3": { "committed": 0,  "total": 20, "status": "folded", "cards": null }
  }
}
```

* `street` — `preflop` / `flop` / `turn` / `river` / `complete`.
* `committed` — вложено на текущей улице (из него считается «доставить»),
  `total` — за всю раздачу (из него строятся сайд-поты). Одно из другого
  не выводится.
* `status` — `active` / `folded` / `all_in`.
* `cards` не `null` только у того, кто открылся сам (§6).
* `deadline_ms` — сколько осталось у ходящего **на момент снапшота**.

Свои карты и своя комбинация лежат в `you`:

```json
"you": {
  "seated": true, "seat": 1, "stack": 940,
  "hole_cards": [{ "rank": 13, "suit": "D" }, { "rank": 13, "suit": "C" }],
  "combination": { "category": "three_of_a_kind",
                   "cards": [{ "rank": 13, "suit": "D" }, "…"] },
  "in_hand": true,
  "legal_actions": { "fold": true, "check": false, "call": 40,
                     "raise": { "min": 80, "max": 940 }, "all_in": 940 }
}
```

* `combination` — `null` до флопа: пяти карт ещё не набирается.
  `category` — атом варианта (`pair`, `two_pair`, `flush`, …), текст
  подписывает клиент.
* `legal_actions` — **единственный источник правды для кнопок**. Пустой
  объект, если сейчас не ваш ход. `call`/`raise` могут быть `null`.

## 3. События раздачи

| Событие | Когда | Payload |
|---|---|---|
| `hand_started` | началась раздача | `{button_seat, players: [{seat, stack}]}` |
| `posted` | анте или блайнд | `{seat, kind, amount, pot}` |
| `your_cards` | **лично вам** | `{seat, cards}` |
| `action_taken` | кто-то сходил | `{seat, action, amount, to, stack, pot, action_seq}` |
| `street_dealt` | открыта улица | `{street, board, pot}` |
| `action_prompt` | чей-то ход | `{seat, action_seq, deadline_ms, legal_actions}` |
| `cards_shown` | игрок открылся в паузе | `{seat, cards}`, закрытая карта — `null` |
| `all_in_showdown` | ставить некому, карты открыты | `{board, players: [{seat, cards}], equity}` |
| `equity_update` | открыта улица при доводке | `{equity}` |
| `hand_finished` | итог | `{board, pots, payouts, rake, showdown, shown, mucked}` |

`your_cards` приходит только владельцу места — в общий топик карманные
карты не уходят вовсе.

`action_prompt` адресован всем: остальные по нему рисуют таймер соперника.
Кнопки показывайте, только если `seat` — ваше место.

`hand_finished`:

```json
{ "board": ["…"], "showdown": true, "rake": 5,
  "pots": [{ "amount": 235, "winners": [1] }],
  "payouts": { "1": 235 },
  "shown": [{ "seat": 1, "cards": ["…"], "category": "flush" }] }
```

`pots` — основной и сайд-поты по порядку; суммы **уже за вычетом рейка**.

---

## 3.1. Олл-ин: открытые карты, шансы и ауты

Когда ставить больше некому, борд **не досдаётся мгновенно**. Сервер
открывает карты всех, кто дошёл, и доводит борд по улице раз в 1.5 секунды —
игрок должен увидеть флоп, тёрн и ривер, а не только итог.

```json
"all_in_showdown": {
  "board": [],
  "players": [{ "seat": 1, "cards": ["…"] }, { "seat": 3, "cards": ["…"] }],
  "equity": [
    { "seat": 1, "win": 0.71, "tie": 0.02, "equity": 0.72,
      "outs": [] },
    { "seat": 3, "win": 0.27, "tie": 0.02, "equity": 0.28,
      "outs": [{ "rank": 12, "count": 3, "cards": ["…"] }] }
  ]
}
```

* `win` / `tie` / `equity` — доли от 1, не проценты. Сумма `equity` = 1.
* `outs` — карты, которые выводят догоняющего вперёд; у лидера список пуст.
  `rank` — достоинство, `count` — сколько таких карт осталось в колоде.
* На каждой открытой улице приходит `equity_update` с пересчитанными
  шансами: после флопа расклад уже другой.
* То же лежит в снапшоте в поле `showdown` — подключившийся в середине
  доводки видит открытые карты и проценты, а не пустой стол.

Считается Монте-Карло на 20 000 итераций: точный перебор пяти неизвестных
карт стоил бы секунду, а полпроцента погрешности игроку незаметны.

## 4. Действия игрока

```
"action" %{type: "fold" | "check" | "call" | "raise" | "all_in",
           amount: 80, action_seq: 12}
```

* `amount` нужен только для `raise` и означает **до какой величины**
  поднимается ставка, а не сколько добавляется сверху.
* `action_seq` — тот счётчик, который клиент видел. Устаревший отвергается
  кодом `stale_action`: это защита от даблкликов и лагов. Поле необязательно,
  но без него защиты нет.
* Границы рейза берите из `legal_actions.raise`, а не считайте сами.

Ошибки: `not_your_turn`, `illegal_action`, `stale_action`, `no_hand`,
`hand_finished`, `not_seated`.

---

## 5. Таймер хода

`action_timeout_ms` лимита (по умолчанию 20 с). Когда время вышло, сервер
ходит за игрока: **чек, если это бесплатно, иначе фолд**. Стол не зависает
никогда.

Клиент рисует таймер от `deadline_ms` и не отправляет ничего сам: автоход —
дело сервера, дублирующий фолд от клиента только создаст гонку.

## 6. Показ карт и мискол

```
"show_cards" %{}              →  :ok   # открыть обе карты
"show_cards" %{"cards" => [1]} →  :ok   # открыть только вторую
```

Показать карты можно **только в паузе после раздачи** — в том же окне,
что и досмотр борда, и той же длины. Во время раздачи показ запрещён:
открытая карта сбросившего подсказывает тем, кто ещё торгуется. Запрос
во время раздачи получает `hand_in_progress`, после окна —
`reveal_unavailable`, повтор уже открытого — `already_shown`.

Своё окно приходит в снапшоте: `you.reveal = {expires_ms, cards, shown,
hidden}`. Кнопку показа рисуйте по `hidden`, а не по своим догадкам о том,
сбрасывали вы или нет.

Что видно на самом деле:

* **на вскрытии** (`showdown: true`) открываются не все. Порядок вскрытия
  — последний агрессор ривера, дальше по кругу; каждый следующий
  открывается, только если бьёт всё показанное до него, а заведомо
  проигравший уходит в **мук**. Открывшиеся приходят в `shown`,
  мукнувшие — в `mucked`. Забравший банк всегда в `shown`;
* **на олл-ине** торговли больше нет, поэтому открываются все участники
  вскрытия — мука не бывает;
* если **все сбросили** (`showdown: false`), не открывается никто:
  победитель показывает карты только сам, через окно после раздачи;
* добровольный показ приезжает событием `cards_shown`, а не в `shown`
  итога раздачи. Уже открытые карты лежат и в снапшоте (`revealed`) —
  вошедший в паузу должен их увидеть.

---

## 7. Деньги

Рейк считает сервер по шаблону лимита (`no_flop_no_drop` учитывается) и
вычитает его из банка **до** раздачи выигрышей. Клиент не пересчитывает
ни банк, ни стеки: и то и другое приходит в событиях и снапшоте.

Проигравший весь стек переводится в `sitting_out` и получает окно на
докупку (§5 задачи 2) — автодокупки нет.

---

## 8. Чего ещё нет

* тайм-банк (поля в шаблоне есть, расход не реализован);
* чат, история раздач, статистика;
* Short Deck и другие варианты: играется только `texas_holdem`.
