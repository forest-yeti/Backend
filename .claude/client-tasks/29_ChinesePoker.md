# Клиент. Задача 29. Китайский покер: вторая дисциплина

Документ для разработчика Electron-клиента. Серверная часть — задача 6
бэкенда.

Новая дисциплина — **OFC Pineapple** (открытый китайский покер, ананас).
Игроки не торгуются и не делят банк: каждый выкладывает тринадцать карт в
три бокса, а по концу раздачи все рассчитываются очками — каждый с каждым
отдельно.

Задача большая: это новый игровой экран, а не правка существующего. Стол,
кнопки ставок, банк, борд и вся торговая часть здесь не используются вовсе.

---

## 1. Что важно понять до вёрстки

**Это не вариант покера, а отдельная дисциплина.** Short Deck (задача 16)
менял колоду и порядок комбинаций, но оставлял тот же экран: улицы, банк,
торговлю. Здесь не остаётся ничего из этого. Экран стола придётся делать
второй, а не настраивать существующий флагом.

**Витрина тоже отдельная.** OFC-столы **не появляются** в общем лобби
(`lobby`) — ни при каких фильтрах. У них свой топик `lobby:ofc` и свой
раздел интерфейса. Это продуктовое решение, а не техническое ограничение.

**Топик стола общий.** Игровой канал остаётся `table:<uuid>`: посадка,
бай-ин, докупка, реконнект, чат, реакции, тайм-банк, кошелёк — всё, что
клиент уже умеет, работает без изменений.

---

## 2. Правила, которые видит игрок

### Ход раздачи

Двое или трое за столом. Колода одна на раздачу, 52 карты.

1. **Первая сдача** — 5 карт, все пять выкладываются в боксы.
2. **Четыре круга** — по 3 карты: две в боксы, одна в сброс.
3. Итого 13 выложенных карт и 4 сброшенных на игрока.

Ходят по очереди. Выложенная карта **не двигается и не снимается** — до
отправки хода клиент вправе двигать карты как угодно, после отправки нет.

### Боксы

| Бокс | Карт |
|---|---|
| `top` | 3 |
| `middle` | 5 |
| `bottom` | 5 |

Рука обязана усиливаться сверху вниз: `bottom ≥ middle ≥ top`. Нарушение —
**фол**: рука мертва, роялти сгорают, игрок проигрывает все боксы каждому
сопернику.

Фол проверяется **только по завершении раскладки**. Недособранная рука
фолом не является, и подсвечивать «сейчас будет фол» на середине раздачи
не надо — это была бы подсказка, которой сервер не даёт.

Верхний бокс расписывается по своим правилам: старшая — пара — сет.
Стритов и флешей в трёх картах не бывает.

### Скоринг

Попарно, каждый с каждым. За выигранный бокс `+1`, за проигранный `−1`,
равенство — `0`. Взявший все три бокса получает **скуп**: `+3` сверх линий,
итого `+6` с этого соперника.

Фолнувший отдаёт каждому нефолнувшему 6 очков плюс его роялти. Оба фолнули
— между ними ноль.

Роялти начисляются поверх линий и **не сравниваются**: их платит каждый
соперник независимо от того, чья рука сильнее.

| Бокс | Комбинация | Роялти |
|---|---|---|
| top | пара 66 … пара AA | 1 … 9 |
| top | сет 222 … сет AAA | 10 … 22 |
| middle | сет / стрит / флеш / фулл-хаус | 2 / 4 / 8 / 12 |
| middle | каре / стрит-флеш / роял-флеш | 20 / 30 / 50 |
| bottom | стрит / флеш / фулл-хаус | 2 / 4 / 6 |
| bottom | каре / стрит-флеш / роял-флеш | 10 / 15 / 25 |

Таблицу **не хардкодить**: посчитанные роялти приходят с сервера в снапшоте
и на вскрытии. Она приведена, чтобы было понятно, что показывать игроку.

### Деньги

Очко стоит `point_value` фишек — это и есть лимит стола, других номиналов
за ним нет. Расчёт по концу раздачи: попарные переносы фишек между стеками.

Стека может не хватить. Тогда перенос урезается стеком должника и делится
между кредиторами пропорционально долгу. Игрок никогда не уходит в минус,
и суммарное число фишек за столом не меняется.

### Фантазия

Верхний бокс `QQ` и выше без фола → игрок в **фантазии**: в следующей
раздаче он получает 14 карт сразу и закрыто и выкладывает их **одним
ходом** (13 в боксы, одна в сброс). Он ходит **первым**, после чего круги
идут только между обычными игроками.

Удержание фантазии: сет в верхнем боксе либо каре и выше в нижнем.

Соперники карт фантазийного игрока до вскрытия не видят — сервер их не
присылает.

## 3. Протокол

### Лобби

Топик **`lobby:ofc`**. Сообщения те же, что у `lobby`: `list`,
`find_by_code`, `quick_seat`, `my_seats`, `ping`. Отличается только форма
строки витрины.

```jsonc
// строка lobby:ofc
{
  "setting_id": "...",
  "name": "OFC 10 3-max",
  "discipline": "ofc_pineapple",
  "currency": "play_money",
  "point_value": 10,      // цена очка = лимит стола
  "bet_unit": 10,         // от него считается бай-ин
  "max_players": 3,
  "min_buy_in": 500,
  "max_buy_in": 2000,
  "table_size": "heads_up",
  "limit_tier": "micro",
  "seats_taken": 1,
  "players_total": 1,
  "rooms": [ ... ],
  "visuals": { ... }
}
```

Полей `small_blind`, `big_blind`, `ante`, `bomb_pot` здесь **нет** — не
показывать их и не подставлять нули.

Обновления приходят тем же `lobby_delta`, но только в этот топик.

### Стол

Топик `table:<uuid>`, как у кэша. Посадка — обычный `join_seat`.

**Клиент → сервер.** Одно новое сообщение:

```jsonc
// place_cards — ход целиком, частичных размещений сервер не хранит
{
  "placements": [
    { "card": { "rank": 14, "suit": "S" }, "row": "bottom" },
    { "card": { "rank": 13, "suit": "S" }, "row": "bottom" }
  ],
  "discard": { "rank": 7, "suit": "D" },   // null на первой сдаче
  "action_seq": 42
}
```

Число размещений и сбросов обязано совпасть с тем, что просит сервер:
первая сдача — 5 и `null`, круг — 2 и одна карта, фантазия — 13 и одна.

Сообщений `action`, `preselect`, `straddle`, `post_blind`, `run_it_twice`,
`rabbit_hunt` за этим столом нет — не отправлять.

**Сервер → клиент.** Личный блок `you` в снапшоте:

```jsonc
{
  "seat": 1,
  "deal": [ ... ],                 // карты на руках — только владельцу
  "rows": { "top": [], "middle": [], "bottom": [ ... ] },
  "royalties": { "top": 0, "middle": 0, "bottom": 2 },
  "legal_actions": {
    "place": 2,                    // сколько карт выложить
    "discard": 1,                  // сколько сбросить
    "rows": { "top": 3, "middle": 5, "bottom": 3 }   // сколько места осталось
  }
}
```

Публичный блок `hand`:

```jsonc
{
  "to_act": 2,
  "action_seq": 7,
  "seats": {
    "1": {
      "rows": { "top": [...], "middle": [...], "bottom": [...] },
      "placed": 7,
      "discarded": 2,     // ЧИСЛО, не карты
      "fantasy": false
    }
  },
  "showdown": null,
  "deadline_ms": 30000,
  "time_bank_running": false
}
```

Полей `board`, `pot`, `bet`, `street` в блоке `hand` **нет вовсе** — не
читать их и не ждать.

Новый код ошибки: **`invalid_placement`** — карта не из сдачи, бокс
переполнен, число размещений не то, ряд назван неверно.

Повтор того же `action_seq` отклоняется как `stale_action` — ровно так же,
как в холдеме.

## 4. Экран

Что должно быть на столе:

1. **Свои три бокса** с подсветкой свободных мест. Карты в них
   зафиксированы — перетащить уже выложенную нельзя.
2. **Рука** — 3 (или 5, или 14) карт, которые надо разложить. Drag & drop
   из руки в бокс плюс кнопка «Сбросить» для лишней карты.
3. **Кнопка подтверждения хода**, неактивная, пока размещено не то число
   карт, которое просит `legal_actions`.
4. **Боксы соперников** — открытые, они публичны с первой же карты.
   У фантазийного игрока боксы пусты до вскрытия, и это надо показать
   явно: «в фантазии», а не «ещё не ходил».
5. **Роялти** своей руки по боксам — из `you.royalties`.
6. **Вскрытие**: три бокса каждого, роялти, очки и изменение стека.
   Фолнувшую руку пометить мёртвой.
7. **Таймер хода** — обычный `action_prompt`, как везде.

Чего на экране быть не должно: банка, борда, кнопок ставок, ползунка
рейза, разбора руки (`hand_insight`), rabbit hunting и предложения сыграть
дважды.

**Сброшенные карты не показываются никому и никогда**, включая владельца
после раздачи. Сервер их не присылает — показывать нечего.

---

## 5. На что обратить внимание

* **Ход отправляется целиком.** Пока игрок раскладывает карты, сервер об
  этом не знает — состояние раскладки живёт только в клиенте до нажатия
  подтверждения. При разрыве связи незавершённая раскладка теряется, и
  сервер по тайм-ауту разложит карты сам.
* **Автораскладка по тайм-ауту не фолит.** Игрок, у которого кончилось
  время, получит разумную раскладку, а не мёртвую руку. Показывать это
  надо как обычный ход, а не как ошибку.
* **Фантазию видно в снапшоте** (`hand.seats[N].fantasy`), и она приходит
  ещё до начала раздачи: место уносит её из прошлой.
* **Двое и трое — разные раздачи.** При двоих 34 карты из 52, при троих
  51: колода сходится впритык, четвёртого игрока за столом не бывает.
