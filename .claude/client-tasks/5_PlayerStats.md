# Клиент. Задача 5. Показатели игроков за столом

Документ для разработчика Electron-клиента. Дополняет
[задачу 2](2_CashGame.md) (канал `table:<room_id>`) и
[задачу 3](3_Hand.md) (раздача): у мест появились **покерные показатели**.

Новых каналов и HTTP-ручек нет.

---

## 1. Что это

Пять классических показателей плюс счётчик сыгранных рук. Показываются
**всем за столом по каждому игроку**: они выводятся из действий, которые
весь стол и так видел, поэтому прятать их бессмысленно.

| Ключ | Что значит | Единица |
|---|---|---|
| `hands` | сыграно рук в этой сессии | штуки |
| `vpip` | доля рук, где игрок добровольно вложил на префлопе | % |
| `pfr` | доля рук с рейзом на префлопе | % |
| `three_bet` | доля использованных возможностей ререйза | % |
| `wtsd` | доля вскрытий среди рук, где игрок увидел флоп | % |
| `af` | агрессия на постфлопе: `(беты + рейзы) / коллы` | отношение |

Важные тонкости, чтобы не спорить с сервером о цифрах:

* Блайнды и анте в `vpip` **не входят** — их не выбирают. Чек большого
  блайнда тоже не считается вложением.
* Знаменатель у `three_bet` — не руки, а *моменты*, когда до хода игрока
  на префлопе уже был рейз. Пас в такой ситуации тоже считается
  использованной возможностью (в знаменателе, не в числителе).
* `af` — не процент. `1.0` — сколько агрессии, столько и коллов;
  `3.0` — втрое больше агрессии. Рисовать как «300%» нельзя.
* Олл-ин, не перебивший ставку, сервер считает коллом, а не агрессией.

## 2. Где брать

### В снапшоте стола

У каждого элемента `seats` появился ключ `stats`:

```json
{
  "seat": 3,
  "user_id": "9f2c...",
  "name": "Hero",
  "stack": 1840,
  "stats": {
    "hands": 42,
    "vpip": 26,
    "pfr": 19,
    "three_bet": 7,
    "wtsd": 31,
    "af": 2.3,
    "aggressive_actions": 23,
    "calls": 10
  }
}
```

### Пушем после каждой раздачи

```
"stats_update"  { "seats": { "1": {...}, "3": {...} } }
```

Приходит один раз за раздачу, сразу после её завершения — между раздачами
показателям меняться не от чего. Ключи — номера мест, значения — тот же
объект, что и `stats` в снапшоте. Заменяй целиком, ничего не досчитывая.

Мест в пуше ровно столько, сколько занято; свободные не приходят.

## 3. Правила отображения

* **Ничего не считай сам.** Проценты уже посчитаны и округлены до целого.
  Складывать, усреднять или пересчитывать их на клиенте нельзя: у процентов
  разные знаменатели, и «среднее по показателям» будет неверным.
* **`null` — это не ноль.** Пока нет знаменателя (не сыграно рук, не было
  возможности ререйза, не доходил до флопа), сервер присылает `null`.
  Рисуй прочерк, а не `0%`.
* **`af` может быть `null` при живой игре.** Отношение не определено, если
  коллов ещё не было. Отличить «пассивен» от «коллов не было» помогают
  `aggressive_actions` и `calls`: если `calls == 0` и
  `aggressive_actions > 0` — это «только агрессия», уместен знак `∞`.
* Порогов сервер не ставит: показатели приходят с первой же руки. Если на
  малой выборке они выглядят дико — это правда о выборке, а не о сервере.
  Хочешь подстраховать игрока — приглушай их визуально по `hands`, но
  данные при этом не искажай.
* `hands` — счётчик **этой сессии**, а не всей истории игрока. Это то самое
  «сколько рук человек уже сыграл за этим столом».

Как рисовать — на усмотрение клиента: компактная строка под ником
(`26/19 · 42`), всплывающая карточка по наведению или отдельная панель.
Важно только, чтобы `af` не выглядел процентом, а `null` — нулём.

## 4. Когда счётчики обнуляются

**Сессия = пребывание за конкретным местом.** В кэш-игре:

| Событие | Показатели |
|---|---|
| сит-аут, пропуск рук | сохраняются |
| разрыв связи и реконнект | сохраняются |
| докупка, нулевой стек | сохраняются |
| **уход с места (cash-out)** | **обнуляются** |
| новый игрок сел на это место | начинает с нуля |

То есть встал из-за стола — статистика стёрта; сел обратно — счёт с нуля.
Клиенту специально ничего делать не нужно: после ухода сервер пришлёт
`stats` с `hands: 0` и `null` в процентах.

Отдельно на будущее: в турнирах правило другое — сессия там равна всему
турниру и переживает пересадку за другой стол. Турниров пока нет, но
не закладывайся в UI на то, что «статистика — это про стол».

---

## 5. Чек-лист приёмки

* [ ] Показатели видны по каждому занятому месту, а не только по своему.
* [ ] `null` рисуется прочерком, а не `0%`.
* [ ] `af` показан как отношение (`2.3`), а не как процент.
* [ ] При `calls == 0` и `aggressive_actions > 0` показатель агрессии
      не выглядит как «нет данных».
* [ ] После `stats_update` цифры меняются без перезапроса снапшота.
* [ ] После ухода игрока и посадки нового на то же место счётчик рук
      начинается с нуля.
* [ ] Счётчик рук совпадает с `stats.hands`, а не с `hands_played` комнаты
      (второе — сколько рук сыграно за столом вообще).
